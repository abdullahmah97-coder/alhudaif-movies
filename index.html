المنصة تجيب بيانات «وين ينعرض» من TMDB (ومصدرها JustWatch). تحتاج مفتاح مجاني من TMDB، تحطه مرة وحدة في الإعدادات ويبقى محفوظ في هالجهاز بس.

يستخدم هذا المنتج واجهة TMDB، وهو غير معتمد من TMDB. بيانات أماكن العرض مقدّمة من JustWatch. themoviedb.org

الإعدادات

مفتاح TMDB

  1. سجّل حساب مجاني في themoviedb.org.
  2. من الإعدادات افتح API واطلب مفتاح للاستخدام الشخصي.
  3. انسخ API Key (٣٢ حرف) أو API Read Access Token والصقه هنا.

المفتاح ينحفظ في متصفح هالجهاز فقط، وما ينرسل لأي مكان غير TMDB.
