# حضيف فليكس · Hudaif Flix

اكتب اسم الفيلم أو المسلسل، ويطلع لك وين ينعرض في السعودية: بالاشتراك، مجاني، إيجار، أو شراء.

- البيانات من TMDB، ومصدر أماكن العرض JustWatch.
- تحتاج مفتاح TMDB مجاني، تحطه في **الإعدادات** داخل الموقع. المفتاح ينحفظ في متصفح جهازك فقط، وما ينرفع لهذا المستودع.
- تشتغل على متصفح التلفزيون (بالأسهم والريموت) وعلى الجوال.

This product uses the TMDB API but is not endorsed or certified by TMDB. Watch-provider data by JustWatch.
